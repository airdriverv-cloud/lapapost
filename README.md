# 🐾 ЛапаПост — сайт о собаках

Статический сайт на чистом HTML/CSS: **10 статей о собаках**, у каждой — своя SVG-иллюстрация.

## Структура
- `index.html` — главная страница с карточками всех статей
- `articles/` — 10 статей (выбор щенка, кормление, вакцинация, дрессировка, лабрадор, уход за шерстью, здоровье, прогулки, подготовка квартиры, социализация)
- `images/` — SVG-картинки к каждой статье
- `css/style.css` — общие стили

## Публикация на GitHub Pages
Settings → Pages → Source: `Deploy from a branch` → ветка `main`, папка `/ (root)`. Сайт станет доступен по адресу `https://airdriverv-cloud.github.io/lapapost/`.

## Запуск локально
Просто откройте `index.html` в браузере.
